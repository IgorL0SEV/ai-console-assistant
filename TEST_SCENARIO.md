# Сценарий проверки для сдачи

## Что запускать

| Команда | Что делает |
|---|---|
| `python assistant.py` | живой ассистент: диалог, режимы, история |
| `python assistant.py --check` | проверяет ключ и список моделей, не тратит токены |
| `python assistant.py --once "Текст" --mode thinking` | один запрос для быстрого скриншота |
| `python assistant.py --demo` | офлайн-демонстрация без ключа, не заменяет живой тест |
| `run.cmd` | то же, что `assistant.py`, с созданием venv |

Перед запуском: `.env` с `PROXYAPI_KEY`, зависимости установлены.

## Живой сценарий

1. Проверка ключа:

   ```powershell
   .\venv\Scripts\python.exe assistant.py --check
   ```

   Снять: «Ключ: задан», количество моделей, обе модели «найдена».

2. Запуск:

   ```powershell
   .\venv\Scripts\python.exe assistant.py
   ```

   Выбрать режим `2` — думающая модель.

3. Первый вопрос:

   ```text
   Привет! Кто ты и как сохраняешь контекст?
   ```

   Снять: баннер провайдера/модели и ответ.

4. Вопрос с рассуждением:

   ```text
   Сколько будет 17*23? Покажи ход рассуждения.
   ```

   Снять: панель «Размышления модели», ответ `391`, строку токенов.

5. Проверка контекста:

   ```text
   Умножь результат на 2.
   ```

   Ожидаемо: модель помнит `391` и отвечает `782`. Это доказывает, что
   история передаётся в запросе.

6. История:

   ```text
   /history
   ```

   Снять: весь диалог с ролями «Вы» и «Ассистент».

7. Переключение режима:

   ```text
   /normal
   Ответь одним словом: столица Франции?
   ```

   Снять: ответ `Париж` и смену модели в статусе/баннере.

8. Вернуться в думающий режим и выйти:

   ```text
   /thinking
   exit
   ```

   Снять: историю при выходе и сообщение «История сохранена».

9. Повторный запуск:

   ```powershell
   .\venv\Scripts\python.exe assistant.py
   ```

   Снять: «Загружена история: N сообщений». Это доказывает загрузку
   истории между запусками.

## Что показать в сдаче

Минимальный набор скриншотов:

1. `--check` — ключ принят, модели найдены.
2. Думающий режим — панель размышлений и токены.
3. Обычный режим — ответ без панели размышлений.
4. Контекст — ответ на «умножь результат на 2».
5. `/history` — история диалога.
6. Повторный запуск — «Загружена история».

Дополнительно можно показать `/status` (провайдер, модели, бюджет,
файлы) и `--help`.

## Соответствие заданию

| Требование | Где видно |
|---|---|
| Обмен сообщениями через ProxyAPI | баннер «ProxyAPI», живые ответы |
| Корректный выход | команда `exit`, история при выходе |
| История между запросами | ответ «782» после «391» |
| История между запусками | «Загружена история» после перезапуска |
| Два режима | выбор `1/2`, `/normal`, `/thinking` |
| Claude 4.5 Sonnet + reasoning | панель размышлений, модель `anthropic/claude-sonnet-4-5` |
| Конфигурация через `.env` | `--check`/`/status`: ключ задан, ключ не печатается |
| Ошибки и таймауты | сообщения об ошибках, тесты `errors.py` |
| Понятные логи запуска | баннер режима, модели и истории |

## Безопасность скриншотов

- Ключ не выводится в интерфейсе и логах.
- `.env` в кадр не попадает.
- В истории могут быть ваши вопросы — не показывайте лишнее.
