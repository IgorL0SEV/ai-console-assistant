# Сценарий проверки проекта

Документ описывает, как убедиться, что консольный ассистент работает:
от офлайн-проверок без ключа до живого диалога с ProxyAPI, историей и
двумя режимами. Сценарий рассчитан на человека, который впервые открыл
проект и хочет повторить проверку самостоятельно.

## Что понадобится

- Python 3.10+ и зависимости из `requirements.txt`.
- Ключ ProxyAPI (`sk-...`) и ненулевой баланс — для живых запросов.
- Интернет к `api.proxyapi.ru`.
- Для офлайн-проверок ключ не нужен.

Подготовка:

```powershell
cd ai-console-assistant
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
# заполнить PROXYAPI_KEY
```

## 1. Офлайн-проверки

Эти шаги не обращаются к API и не тратят токены.

```powershell
python assistant.py --help
python assistant.py --version
python -m unittest discover -s tests -v
python assistant.py --demo
```

Ожидаемый результат:

- `--help` перечисляет режимы, провайдеров и флаги;
- тесты завершаются `OK` (80 проверок);
- `--demo` показывает панели ответа, размышлений, токенов и историю.

Проверка без ключа:

```powershell
python assistant.py --check
```

Ожидаемо: понятное сообщение «Не задан PROXYAPI_KEY…», без трейсбека.
Это подтверждает, что ошибки конфигурации обрабатываются.

## 2. Ключ и модели

```powershell
python assistant.py --check
```

Ожидаемый результат:

- «Ключ: задан»;
- количество доступных моделей;
- обычная и думающая модели помечены «найдена».

Если модель не найдена, проверьте её идентификатор в каталоге ProxyAPI и
исправьте `NORMAL_MODEL` / `THINKING_MODEL` в `.env`.

## 3. Обычный режим

Один запрос без интерактивного цикла:

```powershell
python assistant.py --once "Ответь одним словом: столица Франции?" --mode normal
```

Ожидаемо: ответ «Париж», строка токенов, без панели размышлений.

Интерактивно:

```powershell
python assistant.py
```

Выберите режим `1`, задайте вопрос, затем `/history`. История должна
пополниться парой «вопрос — ответ».

## 4. Думающий режим

```powershell
python assistant.py --once "Сколько будет 17*23? Покажи ход рассуждения." --mode thinking
```

Ожидаемый результат:

- панель «Размышления модели» с ходом решения;
- ответ `391`;
- строка токенов с входом и выходом;
- модель `anthropic/claude-sonnet-4-5`.

В интерактивном запуске это режим `2` или команда `/thinking`.

## 5. Контекст диалога

Проверяется в интерактивном режиме:

```text
Вы: Сколько будет 17*23?
Ассистент: 391
Вы: Умножь результат на 2.
Ассистент: 782
```

Если второй ответ учитывает `391`, значит история передаётся в запросе.
Дополнительно можно открыть `/history` и увидеть обе пары сообщений.

## 6. История между запусками

1. Задайте вопрос и выйдите командой `exit`.
2. Запустите `python assistant.py` снова.

Ожидаемо: «Загружена история: N сообщений». Команда `/history` показывает
прошлый диалог, и его можно продолжить.

Проверить файл:

```powershell
Get-Item data\history.json
```

Команда `/clear` очищает и память, и файл.

## 7. Переключение режимов

В интерактивном запуске:

```text
/mode
/normal
/thinking
/status
```

Ожидаемо:

- `/mode` предлагает выбрать режим;
- `/normal` и `/thinking` переключают модель без потери истории;
- `/status` показывает провайдера, модели, бюджет reasoning и файлы.

## 8. Ошибки (по желанию)

Проверяются на копии `.env` или с временно неверным значением:

- **Неверная модель.** Поставьте `THINKING_MODEL=anthropic/not-a-model`,
  выполните `--once` — ожидается сообщение «модель не найдена» (`404`).
  Верните корректное значение.
- **Нет ключа.** Очистите `PROXYAPI_KEY` — `--check` и `--once` сообщают
  об этом, `--demo` продолжает работать.
- **Нет баланса.** При пустом балансе ProxyAPI вернёт `402`; приложение
  покажет «недостаточно средств».
- **Лимит.** При `429` — сообщение «слишком много запросов».
- **Сеть.** При отключённом интернете — сообщение о связи, без трейсбека.

Ключ и полные промпты в сообщениях об ошибках не печатаются.

## Если что-то не работает

| Симптом | Что сделать |
|---|---|
| `assistant.py` не распознан в PowerShell | запускать `python assistant.py` или `.\venv\Scripts\python.exe assistant.py` |
| `401` | проверить `PROXYAPI_KEY` в `.env` |
| `402` | пополнить баланс ProxyAPI |
| `404` | проверить имя модели в каталоге провайдера |
| `429` | подождать и повторить |
| История не загрузилась | проверить `data/history.json`; запустить без `--no-history` |
| Рамки панелей ломаются в консоли | использовать Windows Terminal или `chcp 65001` |

## Очистка после проверки

- `/clear` — очистить историю диалога.
- Удалить `data/history.json`, если история больше не нужна.
- `.env` остаётся локальным и не попадает в git.
